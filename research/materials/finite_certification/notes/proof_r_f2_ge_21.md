## What failed in analysis

The three new fixed-E11 branch proof directories

- `workspace/data/wang_rep2_seqcnt_proof/`
- `workspace/data/wang_rep10_seqcnt_proof/`
- `workspace/data/wang_rep16_seqcnt_proof/`

were generated by [wang_rep10_seqcnt_proof.py](../../quotient_cores/code/wang_rep10_seqcnt_proof.py).  The script encoded the global equality on the 509 decision variables with overlapping auxiliary variables:

```python
for card in [CardEnc.atmost(dp_lits, target, top_id=top, encoding=EncType.seqcounter),
             CardEnc.atleast(dp_lits, target, top_id=top, encoding=EncType.seqcounter)]:
    top = max(top, card.nv)
```

Both `CardEnc` objects are constructed before `top` changes, so the at-most and at-least encoders reuse the same auxiliary variable numbers.  The resulting formula is inconsistent even without Wang occupation rows.

The decisive reproduction is recorded in [seqcounter_global_cardinality_audit.py](../code/seqcounter_global_cardinality_audit.py) and [global_cardinality_bug_audit.json](../../quotient_cores/results/audit/global_cardinality_bug_audit.json):

- analysis-style global equality alone is UNSAT and has the same 21-byte DRAT hash as the three branch proofs: `da85dff6036cac12fd427db98f2c35e6613339dae6ccba3fdafcbeeea2ba277f`.
- The same equality with disjoint auxiliary ranges is SAT.
- The 153-clause core extracted from the analysis rep2 CNF is identical to the 153-clause core extracted from the isolated faulty global equality.

Therefore the analysis proof objects certify only the inconsistent encoding, not the intended Wang occupation problem.
