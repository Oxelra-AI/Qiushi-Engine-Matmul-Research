## Main results

### Result 1: Laderman does NOT have cyclic Z3 automorphism (definitive)

Three-stage computation over F_{65521}:

**Part A (necessary condition):** Factor rank multiset of Laderman's 23 terms IS consistent with a cyclic automorphism. The multiset has three orbits under cyclic rotation:
- (1,1,1): 13 terms (self-orbit)
- {(3,1,1), (1,3,1), (1,1,3)}: 2 each (balanced 3-orbit)
- (2,2,2): 4 terms (self-orbit)

**Part B (corrected Kronecker search):** The automorphism group of T_{333} has the structure Aut = {(A⊗B^{-T}, B⊗C^{-T}, C⊗A^{-T}) : A,B,C ∈ GL_3} ⋊ S_3. For the sigma^2 direction, B maps a_L → b_L AND B^T maps a_R → c_R (NOT a_R → b_R as the original Part B incorrectly assumed). With this CORRECT coupling:
- 68 candidates pass B left (a_L → b_L) alone
- 10 candidates survive the corrected B^T right check (a_R → c_R)
- 8 candidates for the sigma direction (B: c_L → b_L, B^T: a_R → b_R)

The original Part B search had Q_L and Q_R independent, which is wrong — they must be B and B^T respectively.

**Part C (full 23-term verification):** All 10 sigma^2 candidates FAIL on rank-2 and rank-3 terms. When C is determined from C^{-T} a_R ∝ b_R_π and the full matrix equation B a_l C^{-1} ∝ b_{π(l)} is checked on all 23 terms, no candidate survives.

**Conclusion:** Aut(Laderman) → S_3 has image Z_2 (generated by transpose τ = Φ_3Φ_4), NOT S_3. The kernel is A_4 ⊂ S_4 (alternating group, order 12). Laderman has no cyclic Z3 symmetry and cannot serve as an S3 positive control.

### Result 2: S3 skeleton enumeration

dim(V^{S3}) = (729 + 2·9 + 3·27)/6 = 138.

S3-orbit sizes: 1 (both σ,τ fix), 2 (σ fixes, τ swaps), 3 (τ fixes one, σ cycles), 6 (generic).
Rank-22: a + 2b + 3c + 6d = 22 with:
- f_σ = a + 2b, m_σ = c + 2d (cyclic)
- f_τ = a + c, m_τ = b + c + 3d (transpose)

Applying Cartan m_σ ≥ 4 and anti-sector m_τ ≥ 7: **36 surviving S3 rank-22 skeletons**, all with 198 parameters vs 138 equations (underdetermined, solutions may exist generically).

### Result 3: F5 anti-sector (NEEDS CORRECTION)

The script computed bivectors from FIRST-FACTOR vectors of the transported scheme, but the correct anti-sector bivectors use the SECOND and THIRD factor vectors (the pairing vectors v_l, w_l). The L_anti containment failed (augmented rank 11 ≠ anti span rank 8), confirming the computation error. The decomposable counts (19 for F3, 41 for F5) are for the wrong vector space.

The corrected computation must:
1. Transport ALL THREE factors using the full sandwich (A⊗B^{-T}, B⊗C^{-T}, C⊗A^{-T})
2. Extract the pairing vectors v_l, w_l (second and third factors)
3. Compute bivectors as v_l ∧ w_l for each free pair
4. Count decomposables in the correctly computed anti span

The analysis Q(i) certificate has the correct 8 bivector rows with L_anti containment; the finite-field analogs need the same correct computation.

## Consequences

1. The S3 route remains mathematically valuable (138 equations, 36 feasible skeletons, underdetermined) but has no known positive control.
2. Laderman is Z2-only (transpose), not S3. The BILR scheme has Z3 × Z4 but its Z4 is inner (no transpose); checking BILR for transpose symmetry would determine if any known scheme is S3.
3. The F5 anti-sector count must be redone with correct pairing vectors before any field-dependence conclusion.
4. The noise-first approach to generating anti-feasible spans (choose noise subspace, solve for decomposables) remains the most promising constructive direction.
