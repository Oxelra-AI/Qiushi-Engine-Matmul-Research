# Mathematical Manuscript

**A structural proof of the lower bound 21 for 3 x 3 matrix multiplication
over F2**

- [Paper](main.pdf): mathematical article with four integrated appendices.
- [LaTeX master](main.tex): a single, self-contained AMS article.
- [arXiv submission package](https://github.com/Oxelra-AI/Qiushi-Engine-Matmul-Research/releases/download/paper-revised/Qiushi_Matmul_F2_arxiv.zip): only the LaTeX inputs,
  bibliography, resolved references, and the two printed data tables.
- [Complete source package](https://github.com/Oxelra-AI/Qiushi-Engine-Matmul-Research/releases/download/paper-revised/Qiushi_Matmul_F2_paper_source.zip): manuscript, bibliography,
  finite tables, worked-example data, and manuscript checks.

The paper develops the argument from quotient occupation and affine geometry
to rank saturation and a cross-factor contradiction. The finite bounds are
explained through contraction, substitution, weighted coverage, and integer
branch certificates, with worked examples drawn from the formal proof.
Separate sections explain the Lean formalization and the research decisions
that produced the proof, including a numerical continuation test and the
transition from quotient supports to full-factor compatibility.
The appendices contain the finite premises, a substitution lemma and example,
the complete frozen catalogue, a 23-term witness, and formal interfaces.

## Build

With a standard TeX Live installation, run from this directory:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

All manuscript inputs are included. The build needs no network, Lean
installation or external report. The source ZIPs include `main.bbl`, the resolved
bibliography; a checkout regenerates it with BibTeX. The complete Lean proof
library remains a separate project.

For arXiv, upload `Qiushi_Matmul_F2_arxiv.zip`, select `main.tex` and
PDFLaTeX, and inspect the PDF generated by arXiv before final submission.
The archive excludes build logs, auxiliary files, check utilities, review
records, PDFs, and the Lean and research archives. The complete source
package also includes the manuscript data and checks described below.

To repeat the manuscript's finite-data and typesetting checks, run:

```sh
node tools/check-manuscript.mjs
```

The checker verifies the printed finite tables, numerical examples, source
references, bibliography, and final typesetting logs. It writes its results
to `build/manuscript-checks.json`. The optional
`tools/prepare-data.mjs` regenerates the tables from the sibling formalization;
it is not required for a standalone build.

## Accompanying Materials

The [research repository](https://github.com/Oxelra-AI/Qiushi-Engine-Matmul-Research)
organizes the reports, research trajectory, programs, and proof materials.
The [Lean proof library](https://github.com/Oxelra-AI/Qiushi-Engine-Matmul-Research/tree/lean-formalization/formalization)
provides the matching sources, certificates, pinned dependencies, and
reproduction commands. It is separate from both manuscript source packages.

[Artifact sources](data/artifact-sources.json) identifies the fixed research
archive, the two upstream 23-term schemes, and their coordinate conversions.
[Continuation data](data/continuation-sample.json) records the displayed
numerical values and their sources. The formalization's source identity and
existing kernel-check results are in
[verification record](data/formalization-verification.json).
