# Maintaining This Research Release

This repository contains scientific artifacts, not a running research system.

- Maintain one LaTeX master, main.tex, per language. The Chinese report is a
  faithful translation of the English report, including its research-record
  appendix. Preserve matching equations, references and figures; proof inputs
  remain separate.
- Organize explanations by mathematical questions and dependencies.
- Do not import private execution histories, credentials or host configuration.
- Preserve material corrections and the limitations of the result.
- Never equate a saved success, a timeout, or a local exclusion with a theorem.
- Original binary certificates and tensor data are hash-bound inputs.
- Changes to encoders or proof data require explicit review and a fresh replay.
- Human author order, license decisions and publication approval are not inferred.
- Build reports and run tests before changing release receipts.
- Use a branch and a separate worktree for concurrent tasks.
- No submission or upload is authorized by a local build or test.
